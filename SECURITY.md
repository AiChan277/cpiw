# Security Policy

PrivacyCam is built strictly around the concept of absolute user privacy.

## Privacy Guarantees
- No frame upload to external servers.
- No face identification, biometric tracking, or embedding generation.
- No storage or persistent database of faces.
- No video recording enabled by default or hidden.
- Completely offline operation with zero network access required for inference.

## Reporting a Vulnerability
If you discover a security or privacy vulnerability, please do NOT create a public issue.
Instead, reach out to the core maintainers directly or use the GitHub Security Advisory features if enabled.
We take all privacy-related bugs as critical priority.
